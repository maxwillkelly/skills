# skills
Generic skills that are designed to be used to improve your workflow with AI coding agents

## Available skills

- [follow-pr-template](skills/follow-pr-template/SKILL.md): Follow the repository's pull request template when creating PRs.

## Installation

Install the skill with the [skills CLI](https://github.com/vercel-labs/skills):

```sh
npx skills add maxwillkelly/skills --skill follow-pr-template
```

Add `--global` to make the skill available across projects.
